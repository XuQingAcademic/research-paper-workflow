## 意见登记

复用项目已有修订/反馈记录，保留每条编辑、审稿、作者或导师相关意见的原始编号与来源；没有现成记录的局部任务可在回复中说明，不强制初始化项目。下表是内容映射，不要求新增字段或另一套机器 schema：

| 字段 | 内容 |
|---|---|
| ID | 编辑、审稿人和序号 |
| 来源 | 原消息/意见位置、日期、适用稿件版本；区分用户直接意见、用户转述导师、原始导师材料、公开文献与 AI 审阅 |
| 类型 | scientific / statistical / theoretical / computational / editorial / policy |
| 判断 | valid / partially valid / misunderstanding / unsupported request / unresolved |
| 影响 | A / B / C / D |
| 关联 | claims、theorems、tables、figures、citations、files |
| 动作 | concede / clarify / analyze / revise / push back / decline |
| 验证 | planned / implemented / checked / blocked |
| 剩余限制 | 未解决或新产生的问题 |

审稿材料保持在授权边界内，不把其内容发送到未授权外部服务。

用户说“导师建议……”时，如实保留为用户转述；可在用户授权内用于本稿修改，不要求再次验证导师身份才能推进。它不自动成为已核验导师原话、导师的永久偏好或跨项目规则。AI 圆桌意见也不能写成真人批准。意见来源、作者是否采纳、已执行的修改和核查结果分别记录：采纳不是完成，延期或有理由拒绝不是已实施。

跨阶段任务由 `research-paper-workflow` 的 `references/feedback-and-decisions.md` 协调同一组意见与决定；复用它引用的项目记录，不复制第二份反馈账本。局部写作仍可独立完成，不强制启动完整工作流。

## 诊断与动作

先判断意见触及：

- 研究对象或贡献；
- 识别、假设或定理；
- 估计、推断、算法或计算；
- Monte Carlo 设计和比较公平性；
- 数据、实证解释或经济量级；
- 表图、引用、表达或格式。

优先处理会改变主要结论的问题。不能用大量次要稳健性替代核心识别修复，不能用文字澄清替代理论或代码缺口。

## 影响传播

事实、方法或主张变化时先更新状态账本，再更新正文。检查：

- 摘要、引言和结论；
- 正式定义、假设、定理和证明；
- 模拟 DGP、基准、指标和表图；
- 应用估计、样本、注释和解释；
- 附录、补充材料、复现文件和投稿表单；
- response letter 中的位置引用。

新增分析也可能削弱原主张；不能只把新结果附在末尾而不更新论文主脊。

## 回复写作

每条回复采用：

1. 简洁复述核心问题，避免改变审稿人意思；
2. 明确判断和采取的动作；
3. 给出新证据或推理；
4. 说明稿件具体位置和实质变化；
5. 诚实说明剩余限制。

同意时直接说明修改。部分同意时区分成立与不成立部分。不同意时用证明、反例、模拟、数据或已核对文献支持，不以权威姿态或情绪回应。请求会导致虚构、隐藏结果、违反保密或超出研究设计时，说明不能执行及替代方案。

不要写“已解决”“已充分处理”而没有可定位正文和验证证据。页码可能在排版后变化时，同时给 section、label 或唯一短语。

## 验证与结束标准

对每条已实施意见：

- 检查实际修改文件，而非计划或旧稿；
- 运行受影响的自动化和科学审计；
- 核对 response letter 与稿件位置；
- 检查是否引入新冲突、过度主张或未引用材料；
- 更新状态为 `checked`，记录检查者和日期。

只有所有高严重度意见关闭、明确拒绝并充分说明，或被作者接受为剩余限制后，返修轮次才能结束。未完成项保留在 `unresolved_issues.md`，不得因写完回复信而消失。

## 重要返修的证据优先复审

涉及主要结论、方法有效性或重大审稿意见时，先冻结原意见的验收标准，再让独立新上下文查看旧稿、新稿和实际证据，保存带定位的裁决，最后才提供 response letter 核对。不能先读回复后声称自己“忘记了”。由 `research-paper-workflow/references/evidence-first-review.md` 提供分阶段交接工具；局部编辑不强制增加完整复审。保持既有意见 ID，保留同等有效的替代修复及有证据的不同意。回复信可以指出遗漏的证据，不能靠措辞改变裁决；若需更正，保留原裁决并记录新增证据与理由。
