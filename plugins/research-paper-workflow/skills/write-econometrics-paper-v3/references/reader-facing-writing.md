# 面向读者的问题、贡献与表达

在起草、润色、重写研究主线、定位贡献、改写证明、制作讲解/导师简报或整理符号时读取相关部分。以下是对当前材料的检查，不是交给用户逐题作答的问卷；局部修改只检查受影响内容。

## 按用途交付

| 成品用途 | 读者需要得到什么 | 表达边界 |
|---|---|---|
| 论文正文与证明 | 可引用的对象、条件、结论及足以支持它的论证 | 证明具体连接、速率与独立核验由理论技能负责；不能以直觉稿替代用户要求的完整证明 |
| 理解讲解 | 为什么研究、观察到什么、目标是什么、统计量/决策怎样逐步构造 | 从最小例子进入必要公式，区分总体对象、样本估计、保护余量和最终规则；可暂缓技术细节，但注明结论所需条件 |
| 导师简报 | 问题、核心 insight、最近邻差异、当前结果及值得讨论的选择 | 使用必要公式和可核查结论，按用户指定篇幅、语言与形式取舍；普通 LaTeX 不自动变成 Beamer |

根据请求和已有上下文选择一个用途；不默认一页、不固定句数，也不为说明齐全同时交付三份。用户指定论文式、整段式、紧凑或详细时据此调整；压缩表达不压掉承重条件、证明环节或尚未完成的状态。改变展示用途不改变证据资格。

修改范围按本次对象执行：只改附录、proof 环境或两个解释段时，先保留未授权的正文和其他结构。发现必要的陈述同步或科学缺口时具体指出受影响的位置；已有修复授权覆盖它就同步，没有则交付局部可完成部分与所需决定，不自动升级成全文重写。

## 自然、直接的学术语言

- 使用准确而常见的词、明确的主语和动词。一句承担一个主要判断；条件、机制与结果挤在同一句时，按逻辑拆开，必要关系仍须写清。不设置机械句长上限，也不把所有句子切成碎片。
- 少用破折号插入、层叠同位语、连续多个修饰词和“冒号后再接长句”的结构；直接写清谁做什么、因何得到什么。贡献用完整句子陈述，不用几个抽象名词代替论证。
- 已有明确数学名称时保持该名称，例如 orthogonality、identification、local power。必要时首次简释；不要为避免重复改成含义更模糊的长串描述，也不要为常见概念创造新标签。
- 少用自造复合词和名词堆叠，如无必要，不把量或方法包装成 `quantile-value`、`finite-bank`、`null-compatible` 等标签。保留领域已有且有实际用途的术语，不能机械删除所有连字符或复合词。
- 优先正面说明适用条件和得到的结论。例如“Under A, the expansion holds.”；只有读者可能误认范围、最近邻差别或结论强度时，才补充必要的否定说明。不要逐段重复“这不是……”“它不需要另一结果的……”。
- `pointwise`、`uniform`、`conditional` 等范围在数学陈述和必要解释中准确保留。已有量词与固定对象表达清楚时，避免反复加元评论；不能以“文献一般不强调”为由删除实质限制或暗示更强结论。
- 参考同类论文的行文时，提取可观察的写法：问题如何提出、符号如何引入、结果如何衔接、条件如何解释。沿用原稿中清楚自然的部分；不模仿学者私人身份，不把“顶刊风格”等同于更复杂词汇或更多术语。

## 从研究问题自然引出理论

先写清数据环境和检验/估计问题，让读者知道为什么需要接下来的构造，再引入相应过程、统计量、假设和结论。总体层面的刻画或等价性若解释了统计量的来源，应在相关构造附近出现；不要让读者读完整个方法才发现到底检验什么。

抽象措辞难以理解时，点明实际对象、区间或操作，必要时给一个足以说明问题的短例子。引言只作必要铺垫，不提前复述紧接着会展开的构造；在原句和适当定义处写清，不另加解释自己用词的补丁段落。多步实施过程若用文字重复冗长，可用简洁伪代码表达；不为每个理论结果强加算法框。

具有统一框架时，先给真正通用的目标或限制，再用代表性实例说明覆盖范围。优先用直接可读的等式、不等式或条件矩限制表示 H0/H1；为列举几个例子而额外引入模块集合或多层索引，若不能简化论证就省去。确有数学用途的集合、量词、索引域与模型类必须保留，不能将一种项目写法推广为禁用集合。

定理应接在它回答的问题和必要定义后，并有简短解释说明结论对该问题的意义。多个结果可以集中成理论章节，但必须有清楚的主线和衔接，避免最后一次性罗列全部定理。根据用户选定的研究主线安排篇幅；cross-fitting、网格或求解方式只有在本身构成核心贡献时才主导标题和开篇。

通常不在正文或附录开头另加“各定理作用目录”或冗长证明路线图。证明内部仍应保留必要的 “By Lemma ...” 连接。确有复杂依赖需要导读或用户要求路线图时，提供简短且有用的版本，不把内部检查清单照搬进论文。

内部的版本指纹、证据状态 ID、审核关卡、修复经过和运行代号保留在研究记录或复现资料中。稿件保留读者需要的科学条件、证据限制和方法细节；不能把“检查通过”当研究结果，也不在正式定理标题中留下 “replacement”“verified interface”等修订标记。

## 理论解释也是科学内容

解释定理、条件或机制前，定位它依赖的展开或控制界。先说明哪个主导项需要该条件、怎样闭合，再写解释；“orthogonality and cross-fitting”不能替代实际消掉哪项、控制哪项的关系。正文只需读者理解机制的最短充分说明，不为每个技术细节新增一节。

对拟交付的解释逐句核对对象、方向、范数/索引、条件角色和引用角色，即使显示公式和标签完全未变。常见错位包括：

| 原有证据 | 不得偷换成 |
|---|---|
| 有限样本过程弱收敛到 Gaussian limit | 有限样本过程本身是 Gaussian |
| 加权样本平均误差受控 | 所有观测误差的最大值受控 |
| signed local drift 或指定方向上的变化 | 漂移必定增大，或任意备择功效都提高 |
| 条件矩恒等式刻画 null；另用 completeness 支持识别 | 仅凭该恒等式就得到全局识别，或 completeness 是该恒等式必需条件 |
| 路径距离或 separation bound | 无临界值与协方差分析即可得到拒绝概率比较 |
| 实际采用 cumulative maximum、排序或 rearrangement 中某一操作 | 将不同后处理当作同一操作并继承其速率 |

这些是核对类型，不预设当前论文必有相应结论。发现文字超出证据时，按授权修正措辞或交给理论技能补桥，不用新增重复免责声明掩盖错位。

## 摘要与分支的取舍

摘要优先交代问题、决定性方法关系、已支持的主结果和关键发现。调参、节点数、重抽样次数、求解器及辅助结果仅在理解核心贡献必需时进入摘要；不将摘要写成完成事项清单，也不机械规定句数或必须报告实证。有限 DGP 表现和应用发现保持原范围；未拒绝不支持独立性为真，也不自动支持因果解释。

多个理论分支复用基线定义与已成立结果，用差异展开组织剩余内容：改变了什么对象或条件、新增哪个项、如何处理协方差和校准、得到哪个范围的结论。条件包和承重公式仍须准确引用或保留。已知参数的 fixed-size 结果不自动覆盖估计参数或任意数据选择；估计效应的交叉协方差不能因去重复而遗漏。作者选定证明路线时沿用理论技能 §6 的依赖检查，论文删除失效路线，内部记录保留失败原因。

## 问题与 insight 是否成立

阅读拟交付文本，检查读者能否回答：

- **问题**：在什么观察信息和研究环境下，要判断哪个未知对象或命题？谁需要作这个判断？
- **实际背景**：这个观察限制或决策需求有什么证据？公开数据格式、演示数据或人为粗化分别支持什么，是否被误写成真实业务必要性？
- **摩擦与 insight**：现有方案为什么不能完成该判断；本文利用的关系、几何、分解或识别限制是什么？方法名称、流程描述和“更精确”本身不是 insight。
- **增量**：相对最强适用近邻，改变了什么能力、条件、精度或计算可行性？哪项结果兑现这个变化？
- **判断用途**：这个结果使读者能作出什么新判断，什么情况下仍然不能？零改善、不可识别或不可认证也可以是结果，不靠删去困难设定维持价值。

用当前材料先回答；缺乏真实背景就限制应用措辞，缺乏增量证据就保留候选贡献。不要替用户发明动机或把不确定内容润色成事实，也不要因此阻断已可完成的局部表达。

## 贡献主次与范围

展开提纲或重定主线前，从作者当前决定、最近邻比较和实际结果中恢复：问题与
核心 insight；主要贡献；继承的构造/基准与次要结果；每项新增能力的证据落点。
一页已有设计或几行主脊记录通常足够，不新建问卷或贡献数据库。没有新增证据时
不把篇幅、实现复杂度、统计量数量或新名称当作贡献；比较未闭合的部分保留为待核实。

一般框架、具体估计器的充分条件验证、实际使用的算法分开组织。一个实现例子
可以说明框架可用，但不能限定全部框架，也不能推出所有学习方法都已被覆盖。
主贡献需要足够篇幅说明它相对最强适用近邻新增了什么；切入点、背景结果和长篇
实现检查不与之平分叙事。正文简洁不以删去科学范围为代价。

贡献主次改变后，核对理论引导、模拟与应用分析的关注对象，再根据已兑现结果
重建摘要、引言与结论。已有表格、负结果和约定展示范围仍保留；不把“不重点讨论”
变成“不报告”。统计量选择、固定/加密网格和具体证明路线沿用本项目决定，不能
把一次选择写成所有论文的禁令。局部编辑若不涉及主线，无需重做该定位。

## 最近邻：先做归约，再命名贡献

对足以改变核心贡献判断的最近邻，核对精确来源版本和原文定位，优先做能裁决重合的最小代数归约或条件对照。已完成且对象/版本未变的对照可以复用。以下维度按问题适用性选择，不要求每篇参考文献填全表。

| 比较维度 | 要回答的具体问题 |
|---|---|
| 目标与信息 | estimand、null/alternative、loss、观察信息和渐近序列是否相同？更换名称或应用场景是否改变统计任务？ |
| 统计量关系 | 新统计量是否只是已有量的中心化、缩放、去偏或单调变换？在什么定义域和参数条件下有精确恒等式？ |
| 校准与决策 | 临界值、方差/归一化、尾部方向、随机化/离散边界、调参或选择程序是否对应？统计量有代数关系不自动证明完整检验相同；明确阈值变换及成立条件后才断言决策等价 |
| 假设与速率 | 信息、平滑性、依赖、nuisance、统一性、维数与速率限制哪项改变？放宽一项同时加强另一项时，不笼统称“更弱条件”；逐项列可比部分与代价 |
| 保证与能力 | 区分 size/coverage、power/局部可检测性、识别范围、分辨率和有限样本/渐近结论；一项更强不能代替全部支配 |
| 实现与成本 | 理论对象存在、可行估计、数值上下界及实际计算规模分别做到什么？同目标、信息、校准与预算下才解释性能比较 |

据此分开陈述：**新方法**改变程序或可支持的决策；**新证明**为相同/相关结果提供新的论证；**适用范围拓展**在明确条件、对象或模型类上扩大保证。几类可以并存，但统计量同式时应承认已有构造，不能靠更名声称新统计量；沿用统计量但改进校准、保证或计算时应具体说明那部分增量。

变换恒等式、定向检索和未找到反例均不能独自确认历史首创。无法取得关键原文或尚未完成归约时，标记剩余比较与候选贡献；沿用已有 novelty 检索和发布证据门槛，不添加任意文献数量配额。

## 符号减负与语义保持

- 同一对象保持同一记号；同一局部语境中若同符指代不同对象，先消除歧义。区分总体量、估计量、理想规则与实际计算上包络，不能为了简洁合并。
- 只保留影响当前命题或比较的上下标。约定当前固定的指标后可在正文暂省；给出一次“下文在固定……时记……为……”的对应。进入多样本量、多网格、条件概率或速率比较时恢复必要依赖。
- 抽样随机性、条件信息、样本拆分、模型/版本与函数参数不能因下标显得冗长而消失。符号缩写须可逆地对应原对象，不得把不同估计量、极限对象或证据状态合并。
- 小范围整理可就地说明；涉及多个章节时，在已有术语/符号记录中保留旧—新对应，同步定义、定理、证明、表注和引用它的解释。不要未经保护全局替换 LaTeX 命令、标签、引用键或代码标识。
- 作者锁定符号沿用。未锁定符号的纯改名按局部语义差异检查；若实际改变对象、量词、索引范围或依赖，按 A/B 类变化检查相应证据。没有语义变化时不重跑无关模拟。

先考虑移动参数位置、局部约定和删除重复别名，避免为了“优化”大规模换字母。函数与其函数值、概率分布与经验测度、总体真值与局部序列、原始拟合与后处理估计、训练补集与评估折、理想 bootstrap 分位数与有限抽样临界值，按当前任务逐项辨别；这些区别不能被一个更短的符号吞并。没有对应对象的项目不机械增加这些标记。

迁移后在实际使用位置核对：定义是否变成自我等式，变量是否意外绑定，积分/条件信息与索引域是否改变，不同概率记号是否混用，正文简写能否还原附录的完整对象。仅搜索旧字符串消失或编译成功不足以确认含义保持；跨文件检查见 [cross-artifact-and-release.md](cross-artifact-and-release.md)。

## 紧凑的陈述与完整的证明

在整节、全文或完整证明的读者稿中，先执行段落必要性检查：为每段指定一个
主要功能和它服务的主线对象。若一段不能推进问题、insight、方法、主结果或
解释，也不提供承重定义、证明桥、必要实施或规范位置上的实质限制，则移入附录、
脚注或删除。判断依据是删除后的边际损失，不是该段是否写得流畅或技术上正确。

同时检查主线篇幅：读者应能从正文直接恢复核心问题、决定性 insight、主结果
及其意义。不要用固定字数比例机械验收；但辅助实现、稳健性清单和容易描述的
细节不得挤占主线解释。缺少主线解释时先补足逻辑和直觉，再压缩句子；细节过多
时先移动或删除，单纯改写措辞不能修复信息层级。

假设、定理和推论的陈述集中写适用条件与结论。解释放在邻近正文或确有必要的 remark，点明作用即可；已经声明的条件通过准确引用复用，不重复长篇动机、实现背景或风险提示。辅助技术条件是否放入独立假设取决于引用和复用需要，不能靠省略条件缩短陈述。

普通解释直接融入相邻段落，不逐条包装成编号 remark 或粗体小标题。具有独立条件、额外数学内容或后续引用价值的 remark 可以保留，不设固定数量。

完整证明采用连续段落和必要公式。内部可以分步骤审计，交稿时不默认保留 `Step 1/2/3` 标题；整段式允许按论证转折合理分段，并不要求把所有内容挤成一个段落。保留关键等式/不等式的依据、缩放、作用域、事件概率以及引理衔接。详细程度以读者能复核为准，删除重复解释与低价值展开，不删除完成结论所需的桥梁。

每个论文证明区分四层：证明目标、主路线、关键桥梁和技术闭合。正文保留前三层；
关键桥梁只有在同一对象和作用域的结果已经建立时才能用精确交叉引用代替。
技术闭合原则上移入附录，但不能删除；若它包含新的证明思想、非常规条件、作用域
变化或读者理解结果所需的步骤，则仍留正文。公式承担推导，临近文字说明公式的
目的或结论，不把多个不同桥梁压缩成未经映射的“standard”或“similarly”。

一个只在此处使用的技术步骤可以直接证明，不因内部核查需要就新增 lemma/proposition。真正复用、承担独立关键结论或能明显降低重复的结果再单列。引用前文结论时说明在当前对象上如何适用；用 “analogous argument” 合并相似证明前，核对发生变化的对象、条件、索引与概率结构，至少说明对应关系和新增步骤。不能把一种版本的证明自动赋给带不同漂移、随机集合或估计效应的版本。

删除一段 rate 计算或辅助论证前，追踪它的后续用途。已有证明可准确引用时避免重复；若保留的结论仍依赖该转换或简化速率，就在合适位置保留一次充分论证，并修正指向已删除内容的引用。改动参数或概率界时核对当前 proof、定理以及真实下游依赖，不能只替换一个符号。

用户只要求替换 proof 环境时，保留原定理陈述、已有 label 和周边结构，交付可直接替换的 LaTeX。先检查已提供材料中是否声明所需条件；缺失的前文不能猜补。需要额外条件或命题实质修复时，在成品代码外具体说明其位置与影响；未满足条件的部分保留条件性或未完成状态，不暗中修改原命题，也不声称原命题已证明。用户已授权实质修复时，依理论技能分别记录原命题与修复命题并同步必要文本。

用户问“为什么这一步”“这个符号是什么”时，先解释该步在当前证明中的作用、定义和关键推导，再判断是否需要修改；问题式探索不是自动删除或改写的指令。学习用的中文详细解释与论文证明按要求分别交付，不把教学材料全部塞入正式稿。
