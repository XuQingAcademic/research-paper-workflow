# Controlled manuscript delivery

This entry serves complete LaTeX manuscripts with risk or release evidence. Register the actual project entry and evidence before invoking an editing session. Place the registration and original evidence outside the editor's writable project, and reserve a separate output directory. Draft files and receipts created inside the editor may help its work. The final output path is controlled by the launcher.

A registration names the build entry, a unique insertion anchor in the results section, and the frozen raw event mapping. Preserve the planned unit, design cell, explicit release decision, true metric and strict threshold. For repeated decisions within a unit, provide a distinct within-unit key. Use a stable policy for the denominator. Original records and independent replays keep their declared provenance. With an archived graph and no raw decision records, record the author color semantics, vector source and threshold. Report the author classification and independently verifiable lower bound separately. The supported vector adapter requires the author's known RGB polyline representation.

Register the controlled quantity, original TeX label or statement, scientific assumptions, probability and scope. An expert must confirm that the declaration reflects the cited statement. An expected risk, a population-risk probability guarantee and a finite test error describe different quantities. Add scoped source repairs and guards when a known repeated statement needs revision. If a repair pattern could match a legitimate result, use more specific source bounds. Entries, evidence, and approved corrections belong to the outside registration.

After the editor returns the working source, the launcher invokes:

```sh
python3 scripts/deliver_manuscript.py --project DRAFT --evidence FROZEN_SOURCE \
  --profile TRUSTED_REGISTRATION.json --output CONTROLLED_OUTPUT --deadline-epoch DEADLINE
```

The driver recounts the decisions, validates the registered theorem locators, corrects declared wording, writes the verified results into active TeX, recompiles and reads the result back before atomically creating the output tree. In the registered results subsection, it can consolidate clearly matching prose restatements of a verified replay count. Keep one main result statement and retain the mechanisms, distinct comparisons, and supporting statistics. An ambiguous statement stays in the manuscript for editorial review. Tables, source evidence and theorem statements still follow their original review requirements.

If evidence, source, compiler or deadline fails, the original draft remains available for repair and there is no certified output path. A successful output includes a receipt that binds the input evidence, the source files and the final PDF. Keep independent manuscript and render review appropriate to the delivery scope. This check implements registered evidence and can reject unresolved registered contradictions. Scientific interpretation of a new theorem or arbitrary unregistered claims still requires the relevant specialist review.
