# 把模拟中的错误决定交给写作者

对论文将使用的关键对照、误放或错误拒绝，打开产生结果的记录和对应的理论陈述。先查已有结果，明确每次重复中什么是真值、什么决定算错、哪组重复属于分母。已有逐次数据时直接按完整设计键复算，核对重复 ID 和缺失；仅有作者汇总时按其记录的精度和范围核对。四舍五入的比例无法唯一确定计数时，按原精度引用比例并注明计数未能恢复。数字已可核对时可先写入已有结果记录，复用其输出推进正文。

对于真值严格低于阈值方可放行、真值在单元内固定的结果，可用 [check_false_pass.py](../scripts/check_false_pass.py) 核对实际放行数及其分母。其他规则使用项目的原事件定义，例如真实零假设下的拒绝、逐次真值不同的决策或每次重复中不同的发现数。依据原协议处理未决、超时、失败、恢复及剔除，写出实际总重复数、进入该比例的重复数和排除理由。给类内与类外结果保留独立的观测计数。若指标只为类内定义，类外记为不适用，同时报告范围外实际观察到的决策后果。

给现有结果卡、证据记录或稿件批注补上写作需要的最小信息：

| 交给写作者 | 所需证据 |
|---|---|
| 哪个对照和事件 | 实际输入/表/代码定位，方法、场景、阈值方向（含等号）与统计对象 |
| 观察到多少 | 可核对的次数与实际分母，若有排除同时给总数及原因；零事件按实际分母报告 |
| 数字如何得到 | 来源定位、原判定或复算方式、观察单位与覆盖范围。精确计数、作者已标记的计数、基于可见数据的下界及同设计复跑单独核对 |
| 结果能说明什么 | 定理或方法保证的原文位置与关键前提；该场景如何满足或违反前提、与其他场景的可比性以及对使用决定的影响 |

写作者应能从这条记录复核一个可以直接进稿的陈述。类外误放、类内有限次零误放和定理给出的概率界各有对应范围。适用标签指向待核对的模型设定，实际依据取自理论陈述与生成机制。假设无法从观测量验证时，把这一限制交给写作者。结果并入现有交接即可。

## 数字来源的辨识

从数据字段、图例或生成程序确定数字的直接依据，再选能据此重现的表述：

- 从逐次记录根据信息有资格的完整事件重算时，给出实际计数与分母，注明该次实验或队列。核对原摘要是否用过舍入。若为同设计另行运行，写明是重跑及其设置。
- 作者的颜色、状态字段或标记如果代表对完整运行的判断，按作者定义统计该标记，注明标记所覆盖的场景与单位。从图中重数这些标记依然得到标记事件；要声明几何意义上的越线，须直接核对图坐标与阈值。
- 图中只显示部分时点、曲线被截断，或像素无法区分某些事件时，直接可确认的穿越数只是相应范围的下界。图上分母来自实际可辨认的对象，同设计下不同面板也要分别核对。

同一个结果若有两种可复查但不同的数，保留各自的事件描述、来源和分母，并只向正文传能支持其句子的口径。可将两种结果并列，避免以差值推断图外发生了什么。

## 逐次放行记录

当各次选择出的规则不同、真实风险也不同时，逐次连接决定和该次选中规则对应的真值。用实际项目的统计单位和阈值方向，不对所有重复套同一真值。若项目提供这样的 CSV，可以用 [recount_false_passes.py](../scripts/recount_false_passes.py) 输入完整设计键、各组唯一的重复 ID、决定、真值与阈值列，输出原表指纹、误放编号、分子及两种明确分母。默认等于阈值合格，要求严格低于阈值的设计可用 `--equality-is-violation`。项目使用相反方向或多项风险约束时，按实际决定逻辑从原始记录独立复算。

说明误放次数是除以全部可评单位，还是除以真正发出放行的次数。在没有批准时，后一比例未定义。若源记录有上游失败、未决或排除，保留其标签或给出排除台账。缺少实际受判单位的真值须明确，不能补成零事件。若真值为另一个样本的代理估计，明确写明只能核验其特定代理口径。核对数据支持的最小直接结论后，及时给写作者一段完整的结果陈述。优先完成这段，随后推进可选模拟或整理。
