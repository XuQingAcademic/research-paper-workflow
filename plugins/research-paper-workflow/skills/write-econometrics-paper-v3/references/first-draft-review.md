# 初稿交付检查

适用于首次完整论文初稿的起草和交付。实质性改稿复查受影响的内容。内部提纲、未完成章节、只读诊断、收集意见和指定位置的小改按当轮请求执行。

## 写作前恢复作者决定

先确定活动稿和证据版本，从论文已有状态、作者决定和相关修改记录中恢复仍适用的要求。区分反复适用的写作偏好、某篇论文的科学决定、一次交付的限制。后续明确决定优先。统计量选择、表格取舍、分节位置、数值格式、展示用的简写和计算地点沿用当前论文的决定。讲稿可按听众重新引入符号和缩写，其压缩决定仅用于讲稿。

用 [面向读者的写作指导](reader-facing-writing.md) 先定主线。给主要贡献、继承的构造和辅助结果各自安排位置。接收理论和数值证据时记录实际版本、范围及可以支持的句子。稿件可以先写已有证据支持的部分，设计或计划中的结论留作待办。

## 成稿后检查实际交付物

在作者首次拿到完整稿之前，按下面的次序读回实际稿件并修复有依据的问题。使用现有的理论、模拟、实证及引用核验结果，已有证据仍适用时直接复用。

1. **论证与结构。** 对照最接近的可核验文献，把本文真正增加的对象、条件、方法或保证落到相应结果。正文连贯地呈现问题、重点定理、关键论证和结果解释。将较长的实施说明、机制诊断和辅助证明移到适合的位置，保留关键条件、论证连接和准确引用。编译后确认算法、公式、定理和解释的相对位置便于阅读。精简或移动理论材料后，在同一版本复核假设、作用域、证明桥和结论。
2. **证据与范围。** 用 [模拟与实证写作指导](econometrics-writing-playbook.md#monte-carlo) 核对每项主要论断。模拟的规模、分母和结果取自实际运行，基准方法和 DGP 对应比较问题。size 与 power 用对应的检验、原假设、样本量、估计方法和校准配置，并使表组、方法名、缩写和设计编号可读。校准偏差先定位到有关设置，区分受证据支持的诊断与尚待验证的解释。保留作者指定范围内的完整证据，避免用结果筛选制造方法优势。实证先交代背景、样本、变量与目标，再解释方法改变了什么判断。数据定义、推断方式或数值更正时，沿实际依赖同步表图、图注、正文、附录和摘要性结论。用 [引用工作流](citation-workflow.md) 核对主要假设和主张的来源、原文支持、所引版本与 BibTeX。根据当前论文采用的引用样式检查正文和附录。
3. **学术表达。** 用 [术语规则](terminology-governance.md) 核对专业术语，优先采用最接近文献的名称，用准确的数学关系代替含糊修饰词或临时标签。沿正文阅读顺序检查可能含混的词、符号、缩写和统计量参数，保证首次需要理解时已有定义、公式或精确指引。摘要、可独立阅读的图表和补充材料按各自读者需要提供足够上下文。保留已锁定的称谓和记号。遵循 [学术语言润色规范](academic-humanizer.md)，检查模板化句式、对话口吻和内部写作痕迹，保护数学含义、数字、引文与结论强度。
4. **交付完整性。** 按 [一致性检查](cross-artifact-and-release.md#一致性检查) 核对活动稿、交叉引用、附录和图表。检查拟交付源文件及可见成品是否夹带提示词、聊天答复、内部审阅笔记或意外占位。作者决定暂缓的研究内容如实标注。披露内容与学术表达检查分别处理，按作者决定和适用要求保留声明。整篇 LaTeX 按实际工具链构建并查看相关页面。若交付 Overleaf 包或 PDF，验证包内活动源与展示版本对应，书目、附录和图表均可用。

读回时，先把摘要单独读一遍，再按正文顺序阅读，并把关键图表连同图注单独核对。遇到局部记号首次出现，先确认读者已经知道它指什么。摘要可以直接用文字说出统计量及临界值怎样变化，避免把正文才定义的字母搬进来。对借助分布结论得到临界值或误差界的证明，从原假设重算承重的均值、方差或标准化步骤，再与附录实际推导核对。

## 交付判断

先修复当轮授权且可以解决的问题，再核对所改内容实际进入交付版本。检查位置、结果及未闭合依赖记在已有验证或修改记录中。没有项目账本时可在现有交付说明中简述。证据暂缺时按实际状态交付工作稿，说明受影响的部分与完成条件。准备供作者审阅的初稿使用当前稿件和相应验证，正式投稿的审计与批准按其自身范围执行。
